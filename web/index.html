MNTD LoRa Repeater

LoRaWAN gateway and Meshtastic repeater for the MNTD Goldspot

How this started

I had an MNTD Goldspot sitting on a shelf. It was bought as a Helium hotspot, and once that project wound down it did not earn anything any more. It is a well-made box though: a Raspberry Pi 4 and a RAKwireless concentrator in a solid gold aluminium case, with a proper antenna. Too good to throw away.

So I wanted to give it a second life as something useful for the people around me: a LoRaWAN gateway for The Things Network and other networks, and a Meshtastic repeater, with a clear web page showing everything it hears, relays and sends, all stored in a database.

Along the way the hardware had a few surprises. The concentrator reset turned out to be on GPIO 25, the GPS module on the concentrator is not wired to the Pi on this board, and the LED driver chip is not even fitted, so the front light now shows the Pi's own LEDs. Meshtastic normally needs its own radio, but a small patch to Semtech's driver lets the same SX1302 listen to Meshtastic on its spare channel while the other eight channels keep serving LoRaWAN: one radio, one antenna, both networks.

The first real traffic came in when I moved the box upstairs and connected the antenna: dozens of LoRaWAN devices in the neighbourhood within minutes. A little later the gateway was registered with TTN and sent its first downlinks. Now it runs on a stock Raspberry Pi OS card with one install script, and nothing of the old firmware.
